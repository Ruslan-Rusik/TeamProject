## Команды
**git:**  
- git fetch origin <название ветки> - скачивает изменения с репозитория, но не затягивает их  
- git pull --ff-only origin <название ветки> - безопасно затягивает изменения  
- git merge --no-edit <название ветки> - безопасно сливает ветку

Порядок внесения изменений из своей ветки в main:  
- git switch main  
- git pull --ff-only origin main - затягиваем изменения с главного main в репозитории на наш локальный main  
- git merge --no-edit <своя ветка> - сливаем наш локальный main с нашей веткой  
- git push origin main - отправляем изменения с нашего локального main в главный main

**docker:**  
- docker-compose up - запускает существующие контейнеры  
- docker-compose up --build - создает и запускает контейнеры  
- docker-compose up -d --build - создает и запускает контейнеры в фоновом режиме  
- docker-compose down - удаляет контейнеры
  
Порядок запуска проекта через докер:  
- docker-compose up -d --build (фоновый режим -d по желанию)
